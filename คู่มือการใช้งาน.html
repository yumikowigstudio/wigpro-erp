คู่มือการใช้งาน WigPro ERP

ระบบบริหารร้านวิกผมและร้านตัดผม — ครบทุกฟังก์ชัน ใช้ง่าย

1 เข้าสู่ระบบ

เริ่มใช้งานระบบ

  1. เปิดเว็บเบราว์เซอร์ (แนะนำ Chrome) → ไปที่ลิงก์ระบบที่ได้รับ
  2. กรอก อีเมล และ รหัสผ่าน ที่ได้รับ → กด เข้าสู่ระบบ
  3. ลืมรหัสผ่าน? กด ลืมรหัสผ่าน → ระบบส่งลิงก์รีเซ็ตไปที่อีเมล
💡 กด "เพิ่มลงหน้าจอโฮม" บนมือถือ เพื่อใช้เหมือนแอป

2 ตั้งค่าร้านครั้งแรก (ทำก่อนเริ่มขาย)

กรอกข้อมูลร้านให้ครบ เพื่อให้ใบเสร็จสมบูรณ์

  1. ไป ตั้งค่า → ข้อมูลร้าน → กรอกชื่อร้าน, ที่อยู่, เบอร์, เลขผู้เสียภาษี, โลโก้ → บันทึก
  2. ตั้งค่า → สาขา → เพิ่มสาขา (ถ้ามีหลายสาขา)
  3. ตั้งค่า → พนักงาน → เพิ่มพนักงาน + กำหนด % ค่าคอมมิชชั่น
  4. ตั้งค่า → ภาษี & การเงิน → ตั้ง VAT (7%) และข้อความท้ายใบเสร็จ
  5. เพิ่มสินค้าและบริการ (ดูหัวข้อ "สินค้า")

3 แดชบอร์ด

ภาพรวมธุรกิจในหน้าเดียว

  • ดูยอดขาย, คิววันนี้, งานผลิตค้าง, ลูกค้าใหม่
  • กราฟรายได้ 6 เดือน + สินค้าใกล้หมด
  • เลือกช่วงเวลา (วันนี้/สัปดาห์/เดือน/ปี) มุมขวาบน

4 ขายหน้าร้าน (POS)

คิดเงิน ออกใบเสร็จ พร้อมส่วนลด/คูปอง/คอมมิชชั่น

ขายปกติ

  1. เลือกแท็บ สินค้า หรือ บริการ → กดสินค้าเพื่อใส่ตะกร้า (กด +/− ปรับจำนวน)
  2. (ไม่บังคับ) ค้นหา/เลือก ลูกค้า ทางขวา
  3. (ไม่บังคับ) เลือก ผู้ขาย ใต้แต่ละรายการ → ระบบคิดค่าคอมให้อัตโนมัติ
  4. ใส่ ส่วนลด (% หรือ บาท) หรือ รหัสคูปอง แล้วกด "ใช้"
  5. เลือกวิธีชำระ: เงินสด / โอน / QR / บัตร (โอน/QR/บัตร แนบสลิปได้)
  6. กด ชำระเงิน → กด พิมพ์ใบเสร็จ (เลือก Save as PDF ได้)

หักมัดจำเดิม

ถ้าลูกค้าเคยวางมัดจำไว้ → เลือกลูกค้าคนนั้น → จะมีกล่อง "หักมัดจำเดิม" ให้ติ๊ก → ยอดชำระจะลดลง

💡 การขายจะตัดสต๊อกให้อัตโนมัติ

5 รับมัดจำ + สั่งทำวิก

รับเงินมัดจำ + สร้างใบสั่งผลิตวิกอัตโนมัติ

  1. ที่ POS กดปุ่ม วางมัดจำ (มุมขวาบนของตะกร้า)
  2. เลือกลูกค้า + ใส่สินค้า/วิก + กรอกรายละเอียดวิก (ประเภท/สี/ความยาว)
  3. ใส่ ยอดมัดจำ + วันนัดรับ → กด รับมัดจำ
  4. ระบบออกใบมัดจำ (แสดงยอดเต็ม/มัดจำ/คงเหลือ) + สร้างใบสั่งผลิตวิกอัตโนมัติ พร้อมเลขออเดอร์รันตามสาขา

6 คืน / เปลี่ยนสินค้า

รับคืนสินค้า + คืนสต๊อกอัตโนมัติ

  1. เมนู คืน/เปลี่ยนสินค้า → ใส่ เลขที่ใบเสร็จ (RCP-...) → ค้นหา
  2. เลือกจำนวนที่จะคืนของแต่ละรายการ + เลือกวิธีคืนเงิน
  3. กด ยืนยันคืนสินค้า → สต๊อกจะเพิ่มกลับอัตโนมัติ

เปลี่ยนสินค้า: คืนของเก่า แล้วขายชิ้นใหม่ที่ POS

7 ลูกค้า (CRM)

เก็บข้อมูลลูกค้าครบทุกด้าน

เพิ่มลูกค้า

  1. เมนู ลูกค้า → เพิ่มลูกค้า → กรอกข้อมูล + เคส (คีโม/ผมบาง ฯลฯ) + ขนาดศีรษะ → บันทึก

เปิดข้อมูลลูกค้า (แท็บต่างๆ)

  • ภาพรวม — ข้อมูลหลัก
  • รูปภาพ — อัปโหลดรูป Before/After, ใบเสร็จ, ใบออเดอร์วิก
  • ผลบริการ — บันทึกผลบริการ + คำแนะนำ + รูปก่อน/หลังทำ
  • เอกสาร / ประวัติบริการ / การชำระเงิน / ติดต่อ / งานผลิตวิก

8 นัดหมาย

จองคิว + ซิงค์ Google Calendar

  1. เมนู นัดหมาย → สร้างนัดใหม่ → กรอกลูกค้า/บริการ/ช่าง/วันเวลา
  2. เปิด toggle Sync Google Calendar (ถ้าเชื่อมต่อแล้ว) → นัดจะขึ้นปฏิทิน Google อัตโนมัติ
💡 ต้องเชื่อม Google Calendar ที่ ตั้งค่า → Google Calendar ก่อน

9 สมาชิก

จัดการระดับสมาชิก (Silver/Gold/Platinum/VIP) และแต้ม

10 สินค้า

จัดการสินค้า ราคา ต้นทุน รูป

  1. เมนู สินค้าและสต๊อก → รายการสินค้า → เพิ่มสินค้า
  2. กรอกชื่อ/SKU/ราคาขาย/ต้นทุน/รูป/หมวดหมู่ · ตั้ง "เป็นวิก" ถ้าเป็นสินค้าสั่งผลิต → บันทึก
  3. แก้ไข/ลบ: กดเข้าสินค้า → แก้ไข หรือ ลบ

11 สต๊อก

รับเข้า ปรับ ตรวจนับ ดูประวัติ

  • เมนู สินค้าและสต๊อก → สต๊อกสินค้า
  • ปรับสต๊อก — แก้จำนวนคงเหลือ (รับเข้า/ตรวจนับ)
  • ดูสินค้าใกล้หมด + ประวัติการเคลื่อนไหว

12 โอนสินค้าข้ามสาขา

โอนสต๊อกระหว่างสาขา (สำหรับร้านหลายสาขา)

  1. เมนู โอนสินค้า → ครั้งแรกกด Seed ที่แต่ละสาขา (นำสต๊อกเข้าคลัง)
  2. กด สร้างใบโอน → เลือกสาขาต้นทาง/ปลายทาง + รายการ + จำนวน → ยืนยัน
  3. เปิดสาขาใหม่? กด Clone เพื่อโคลนรายการสินค้าเข้าสาขาใหม่ (จำนวน 0)

13 งานผลิตวิก

ติดตามใบสั่งผลิตวิก

  • เมนู งานผลิตวิก → เปิดใบสั่งผลิต (สร้างอัตโนมัติจากการรับมัดจำ)
  • กรอกช่องคนผลิต / ถุงเก็บ · เปลี่ยนสถานะงาน · อัปโหลดรูปงาน

14 มัดจำ (ติดตามยอดคงเหลือ)

ดูมัดจำค้าง + รับชำระยอดคงเหลือ

  1. เมนู มัดจำ → เปิดรายการที่ค้าง → กด จ่ายยอดคงเหลือ เมื่อลูกค้ามารับงาน

15 ใบเสนอราคา

สร้างและพิมพ์ใบเสนอราคา

  1. เมนู ใบเสนอราคา → สร้าง → ใส่ลูกค้า + รายการ → บันทึก → กดไอคอนพิมพ์ 🖨️

16 บัญชี

รายรับ รายจ่าย กำไร + Export

  1. เมนู บัญชี → เพิ่มรายจ่าย (ค่าเช่า/ค่าไฟ ฯลฯ)
  2. ดูสรุป รายรับ/รายจ่าย/กำไร · กด Export CSV เปิดใน Excel ได้

17 คอมมิชชั่น

ดูค่าคอมพนักงานรายเดือน

  1. เมนู คอมมิชชั่น → เลือกเดือน → ดูยอดคอมของพนักงานแต่ละคน (คิดจากการขายที่ระบุผู้ขาย)

18 รายงาน

วิเคราะห์ธุรกิจ

  • เมนู รายงาน → แท็บ: ยอดขาย / ลูกค้า / สินค้า (รายได้แยกสินค้า-บริการ) / งานผลิต / คอมมิชชั่น
  • เลือกช่วงเวลา + กด Export CSV

19 ตั้งค่าระบบ

จัดการทุกการตั้งค่า

  • ข้อมูลร้าน — ชื่อ/ที่อยู่/เลขภาษี/โลโก้ (ขึ้นบนใบเสร็จ)
  • สาขา / พนักงาน / สิทธิ์การใช้งาน — จัดการทีมงาน + สร้างผู้ใช้
  • ภาษี & การเงิน — VAT, ข้อความท้ายใบเสร็จ
  • คูปองส่วนลด — สร้างรหัสคูปอง (% หรือ บาท + วันหมดอายุ)
  • LINE OA — เชื่อม LINE (มีคู่มือในหน้า)
  • Google Calendar — เชื่อมปฏิทินสำหรับซิงค์นัดหมาย

? ปัญหาที่พบบ่อย

ลืมรหัสผ่าน

หน้า login → กด "ลืมรหัสผ่าน" → เช็คอีเมล (หรือแจ้งผู้ดูแลระบบให้รีเซ็ตให้)

ใบเสร็จไม่มีข้อมูลร้าน

ไป ตั้งค่า → ข้อมูลร้าน แล้วกรอกให้ครบ + บันทึก

ข้อมูลไม่อัปเดต / โหลดค้าง

กด Ctrl+Shift+R (รีเฟรชแบบล้าง cache) หรือ ล็อกเอาต์แล้วเข้าใหม่

ขายแล้วไม่มีสินค้าให้เลือก

ต้องเพิ่มสินค้าที่ สินค้าและสต๊อก → รายการสินค้า ก่อน

⚠️ ต้องการความช่วยเหลือ ติดต่อผู้ดูแลระบบ (ผู้ขาย/ผู้ติดตั้ง)
